Verdant Sentinel

A self-contained HTML5 Canvas simulation: a procedurally animated plant creature intercepts alien-like creatures as they rush in from the right on oscillating paths.

## Run it

1. Open `verdant-sentinel.html` in VS Code to view or edit the source.
2. Open the same file in a browser to run the simulation. No server, packages, or build step are required.

## Controls

- **Pause / Resume** toggles the simulation.
- **Send a wave** sends a group of additional creatures.
- **Restart** resets the score and starts a fresh run.

## What’s inside

- One HTML file containing all markup, styles, and JavaScript.
- Canvas rendering for the environment, plant, creatures, tendrils, and effects.
- Procedural plant sway, multiple simultaneous feeding tendrils, and oscillating creature movement.
- Score, active-creature count, and threat-level display.

## Edit

The simulation logic and drawing functions are in the `<script>` block near the end of `verdant-sentinel.html`. The page layout and styling are in the `<style>` block in the document head.
